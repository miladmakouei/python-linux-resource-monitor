

# Linux System Resource Monitor

ابزاری برای بررسی وضعیت منابع سخت‌افزاری سیستم‌های Linux که اطلاعات CPU، RAM، فضای دیسک و پردازش‌های پرمصرف را در ترمینال نمایش می‌دهد.

هدف این پروژه ارائه یک گزارش سریع از وضعیت سیستم و شناسایی مصرف بالای منابع است.

## امکانات

- نمایش درصد مصرف CPU
- نمایش میزان استفاده و حافظه آزاد RAM
- بررسی فضای استفاده‌شده و آزاد دیسک
- نمایش پنج پردازش پرمصرف از نظر RAM
- هشدار برای مصرف بالای CPU، RAM و دیسک
- نمایش زمان تهیه گزارش

## فناوری‌های استفاده‌شده

- Python 3
- psutil
- datetime

## پیش‌نیازها

- Python 3
- Linux
- کتابخانه psutil

## نصب و اجرا

ابتدا مخزن را دریافت کنید و وارد پوشه پروژه شوید.

ساخت محیط مجازی:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

نصب وابستگی‌ها:

```bash
pip install -r requirements.txt
```

اجرای برنامه:

```bash
python3 main.py
```

## تنظیم آستانه هشدارها

در ابتدای فایل `main.py` سه مقدار برای هشدار تعریف شده است:

```python
CPU_WARNING = 80
RAM_WARNING = 80
DISK_WARNING = 85
```

برای مثال، با تغییر `RAM_WARNING` به 90، هشدار مصرف بالای RAM زمانی نمایش داده می‌شود که میزان استفاده به 90 درصد یا بیشتر برسد.

## محدودیت‌ها

- در نسخه فعلی فقط پارتیشن ریشه سیستم بررسی می‌شود.
- گزارش فقط در ترمینال نمایش داده می‌شود.
- برنامه به‌صورت دائمی در پس‌زمینه اجرا نمی‌شود.
- اطلاعات پردازش‌ها ممکن است تحت تأثیر محدودیت دسترسی سیستم قرار بگیرند.
- این ابزار جایگزین سامانه‌های حرفه‌ای مانیتورینگ نیست.
